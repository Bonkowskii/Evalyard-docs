# Evalyard Docs (Docusaurus v3)

- Domain: https://docs.evalyard.com
- Markdown lives in: `docs/`
- Sidebar config: `sidebars.ts`
- Navbar links: set in `docusaurus.config.ts`

## Dev
npm i
npm run start

## Build
npm run build
# output folder: build/


## Cloudflare Pages
Set environment variable `NODE_VERSION=20.18.1` (or add `.nvmrc` as provided).
